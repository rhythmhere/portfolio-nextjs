# Rhythm Bhattarai — Creative Developer Portfolio

A premium, high-performance scrollytelling personal portfolio built to showcase professional experiences and shipped projects. Designed with a vibrant, modern aesthetic focusing on seamless scroll-linked animations and smooth micro-interactions.

## ✨ Features

- **Scrollytelling Experience**: Advanced scroll-linked animations crafted with Framer Motion.
- **Hardware-Accelerated Effects**: Dynamic background lighting and blur effects for a premium feel.
- **Modern Tech Stack**: Built on the robust foundation of Next.js 14 (App Router) with React 18.
- **Fully Responsive**: Flawless experience across mobile, tablet, and desktop viewports.
- **Dynamic Content**: Sections for Projects, Experience, Education, Skills, and more.

## 🛠️ Technology Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/icons/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

Follow these steps to run the portfolio locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/rhythmhere/portfolio-nextjs.git
   cd portfolio-nextjs
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
